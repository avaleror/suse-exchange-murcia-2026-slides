# Cloud Native y Modernización con SUSE Rancher Prime & SUSE Virtualization

Slides de la charla de Andrés Valero en **SUSE Exchange Murcia 2026**, en Slidev.

**Ver las slides:** https://avaleror.github.io/suse-exchange-murcia-2026-slides/

Cómo gestionar Kubernetes en producción con SUSE Rancher Prime y llevar las máquinas virtuales a una plataforma hiperconvergente y abierta con SUSE Virtualization. 19 slides de charla y un anexo para las preguntas.

Navegación: flechas o espacio. `o` abre la vista general, `p` el modo presentador con notas. Abajo, Geeko recorre los capítulos de la charla.

## En local

```bash
npm install
npm run dev      # http://localhost:3030
npm run export   # PDF (necesita playwright-chromium)
```

## Estructura

- `slides.md`: las slides y las notas del ponente
- `layouts/s.vue`: layout SUSE con fuentes enlazadas y Geekos animados (`geeko:` en el frontmatter)
- `global-top.vue`: la barra de capítulos con Geeko
- `theme/`: tema SUSE (fuentes SUSE, paleta y recursos oficiales de marca)
- `style.css`: cards, diagramas y animaciones
